# STT / TTS — Qwen

Ветка `qwen-speed` основана на `qwen-only` и оставляет три модели Qwen:

| Задача | Модель |
|---|---|
| Распознавание речи и звука видео | `Qwen/Qwen3-ASR-0.6B` |
| Синтез со встроенными голосами | `Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice` |
| Клонирование по сохранённому образцу | `Qwen/Qwen3-TTS-12Hz-0.6B-Base` |

Исходный код находится в `C:\Users\andre\stt_tts`. Веса, окружения,
сохранённые пользовательские голоса, кэши, временные файлы и логи находятся
в `D:\Games\STT_TTS_project`. Веса других моделей, скачанные до перехода на
эту ветку, не используются приложением. Они не входят в Git и не удаляются
переключением ветки.

## Запуск

В PowerShell:

```powershell
cd C:\Users\andre\stt_tts
.\start.ps1
```

Если используется cmd, запусти `powershell -NoProfile -ExecutionPolicy Bypass
-File "C:\Users\andre\stt_tts\start.ps1"`. Открой
<http://127.0.0.1:8090/>. Остановка — Ctrl+C в окне сервера. Если сервис
уже работает, останови его перед запуском этой ветки.

## Установка с нуля

```powershell
.\scripts\setup.ps1
.\scripts\download-model.ps1
.\scripts\setup-tts.ps1
.\scripts\setup-qwen-clone.ps1
.\start.ps1
```

Установочные скрипты этой ветки загружают только Qwen. Основное окружение
ASR — `D:\Games\STT_TTS_project\envs\py312`; отдельное окружение TTS —
`D:\Games\STT_TTS_project\envs\tts` из-за разных версий Transformers.

## Возможности

- Файл WAV/MP3/M4A/WebM/MP4 либо запись микрофона → текст на языке записи.
  Файлы видео распознаются по звуковой дорожке. Есть предварительный текст
  в режиме микрофона; он получается повторным распознаванием накопленного
  аудио. Финальный ответ использует готовый предварительный результат, если
  новых аудиоданных не поступило.
- Ввод или загрузка UTF-8 TXT → синтез WAV одним из встроенных голосов Qwen.
- Загрузка образца голоса 3–30 секунд → сохранение WAV на D: → выбор
  пользовательского голоса в Qwen Base. Образец загружается один раз.
  Расшифровку образца можно сохранить рядом с ним; без неё используется
  только тембр. Старые сохранённые голоса остаются доступными через их WAV.
- Перед синтезом работает собственная нормализация русских дат, времени и
  температур из `src/stt_tts/text_normalization.py`.

Сервис пока не содержит LLM-агента и не анализирует видеокадры. Qwen ASR
выгружается перед TTS на RTX 3050 4 ГБ. TTS работает в долгоживущем процессе:
последовательные запросы к одной модели используют уже загруженные веса.
При переходе к ASR процесс TTS останавливается для освобождения видеопамяти.
Переключение между встроенными и пользовательскими голосами меняет модель и
требует её загрузки. Подготовленный образец клона повторно используется при
неизменных WAV и тексте образца.

## API

| Маршрут | Действие |
|---|---|
| `GET /health` | Состояние моделей и сервиса |
| `POST /api/transcribe` | Multipart: `file`, `engine=qwen`, необязательный `context` |
| `GET /api/stream` | WebSocket: моно PCM16 16 кГц, `engine=qwen` |
| `POST /api/tts` | JSON: `text`, `engine=qwen` или `qwen_clone`, `speaker`, необязательный `ref_text` |
| `GET/POST /api/voices` | Список и сохранение пользовательских голосов |
| `GET /api/voices/{id}/audio` | Прослушивание сохранённого образца |
| `DELETE /api/voices/{id}` | Удаление пользовательского голоса |
| `PUT /api/voices/{id}/transcript` | Сохранение текста образца |

План ускорения, исходные измерения и результаты первого замера:
[docs/optimization-plan.md](docs/optimization-plan.md). Старые исследования
в `docs/` сохранены как исторические отчёты; они не описывают активные
движки этой ветки.
