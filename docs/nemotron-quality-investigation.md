# Nemotron 3.5 ASR 0.6B: проверка качества русской записи

Дата: 30 октября 2026. Образец: `C:\Users\andre\Downloads\Академия Печати 3.m4a`,
32,28 с, декодирован без изменения темпа в моно PCM16 16 кГц. Это одна запись,
поэтому вывод не является оценкой качества модели на всех русских аудио.

## Ошибки, важные пользователю

На исходной записи Nemotron GGUF Q8_0 (ревизия `1c8deae`) распознал
«с задним уходом» и «допустил на ясно арку в языкных ворот». Более удачная
расшифровка Qwen3-ASR-0.6B того же файла содержит «задним ходом» и
«допустил наезд на арку въездных ворот». Точная дословная разметка всего файла
не подтверждена человеком, поэтому CER/WER здесь не приводятся.

## Проверенные варианты Nemotron

| Вариант | Наблюдение |
|---|---|
| Offline, `language=auto` и `ru-RU` | Результат одинаковый; ключевые ошибки остаются. |
| Offline, правый контекст 3 и 13 кадров | Результат одинаковый: в offline режиме параметр фактически не менял путь декодирования. |
| Настоящий streaming с правым контекстом 0, 1, 3, 6, 13 | При 13 кадрах появилось «въездных ворот», но «задним уходом» и ошибка в «наезд» остались. При меньшем контексте результат хуже или сопоставим. |
| Разбиение записи по 16 или 10 секунд | «Въездных ворот» иногда восстанавливается; «задним уходом» остаётся, на границах фрагментов появляются новые ошибки. |
| Замедление без изменения высоты тона до 0,9× | «Задним ходом» восстановилось, но появились другие ошибки: «арковизных ворот», «тест» вместо «ТС». Ускорение до 1,1× ухудшило результат. |
| Словарные подсказки на установленном GGUF | Runtime сообщает, что в старой ревизии нет встроенного SentencePiece; усиление отключено. |
| Последний GGUF `ea30d66` / SHA-256 `3fc991d3…` | Обычный результат сопоставим со старым. Усиление отдельных слов 0,5–1 не помогло; сила 2 ухудшила фразу, 3 для длинных фраз дала пустой текст. |

Qwen3-ASR на том же образце вернул «задним ходом» и «наезд на арку въездных
ворот» без ручной коррекции. Его измеренное время собственно распознавания
составило 7,63 с; загрузка модели в этот показатель не входит. Эти измерения
не позволяют сравнить задержку с постоянно загруженным Nemotron без отдельного
контролируемого теста.

## Вывод

Подбор параметров декодирования и простая обработка аудио не обеспечили
приемлемой точности Nemotron на этой записи. Установленная версия остаётся
экспериментальным движком; Qwen остаётся штатным выбором для точной русской
расшифровки. Подмена ошибок заранее известными словами не применяется.

Дообучение весов потребует набора аудио с проверенными дословными текстами,
отдельного обучающего окружения и независимой проверочной выборки. Одного
32-секундного файла недостаточно, чтобы получить и подтвердить общее улучшение.
Веса Nemotron лицензированы по OpenMDW 1.1, не Apache 2.0.
