# Как хранятся голоса в локальном сервисе

## Готовые голоса и клонирование — разные механизмы

У **Qwen3-TTS CustomVoice** имена `Serena`, `Ryan` и другие соответствуют
идентификаторам говорящих в конфигурации модели (`talker_config.spk_id`).
Модель обучена на этих голосах: при запросе приложение передаёт ID, а веса
модели формируют нужный тембр. Отдельная пользовательская запись не нужна.
Это не «загрузка файла голоса на каждый запрос».

У **Qwen3-TTS Base** и **CosyVoice3** сохранённый пользовательский голос —
не новая обученная модель. WAV служит образцом для извлечения признаков и
контекстом генерации. Веса базовой модели не изменяются. FireRedTTS3-Base
использует тот же общий принцип zero-shot клонирования: образец аудио +
точная расшифровка образца + новый текст. При запуске через CrispASR без
образца доступен один встроенный англоязычный пример голоса; это не набор
русских готовых голосов.

## Текущее хранение

Образец загружается **один раз** через «Мои голоса» и сохраняется на D:.
Каждый голос имеет случайный ID `clone-...` и два файла:

```text
D:\Games\STT_TTS_project\voices\clone-<id>.wav   # исходный образец
D:\Games\STT_TTS_project\voices\clone-<id>.json  # имя, длительность,
                                                     # MOSS-коды и ref_text
```

Поле `ref_text` — точная расшифровка образца. В веб-интерфейсе её можно
получить кнопкой распознавания, исправить и сохранить. При следующем выборе
того же голоса текст подставляется автоматически. API принимает ID голоса,
а если `ref_text` не передан, берёт его из сохранённого профиля. Для
CosyVoice3 расшифровка обязательна, для Qwen Base возможен режим без неё.
Старые профили без `ref_text` продолжают работать; текст нужно сохранить
один раз для соответствующего образца.

## Дальнейшая оптимизация

Для каждого движка можно отдельно кэшировать вычисленные признаки образца:
speaker embedding, акустические токены, латенты и т. п. Их нельзя свободно
переносить между Qwen, CosyVoice и FireRed: форматы и кодеки разные. Ключ
кэша должен включать хеш WAV, точный текст образца, движок, ревизию весов и
версию препроцессора. WAV остаётся источником истины; при смене модели
признаки пересчитываются. Пока проект сохраняет WAV и MOSS-коды, а Qwen и
CosyVoice пересчитывают свои признаки при генерации.
